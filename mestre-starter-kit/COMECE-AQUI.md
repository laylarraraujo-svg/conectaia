# 📦 mestre-starter-kit — referência de método do seu squad

Esta pasta é a base de método dos seus agentes: o curso **Mestre do Claude** (aulas + skills de tutor) que ensina a construir, conectar e colocar agentes pra rodar.

## Pra que serve
Todo CLAUDE.md do seu squad tem uma regra: quando você pedir ajuda pra **construir, implementar, criar uma skill ou conectar uma ferramenta**, o agente consulta este kit antes de improvisar.

## Como obter o kit completo
O kit completo está como material do curso **Mestre do Claude** na plataforma AI Deploy Club (Biblioteca → materiais da aula → `mestre-starter-kit.zip`). Baixe, descompacte aqui dentro, abra esta pasta no Claude Code e mande **"oi"** pra ser guiado passo a passo.
